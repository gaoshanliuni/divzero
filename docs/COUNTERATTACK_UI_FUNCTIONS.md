# 本地反击和界面功能补齐 · 1.0.23 候选

## 战斗

读取真实运行攻击的冷却与分别限制近战/远程的硬直，结合接近时间、自身冷却和仍在飞行的攻击决定反击窗口。风险评分在窗口内允许前进，射击间隔也可用于分段接近。安全直线路径和头顶空间允许原生疾跑跳跃；不修改速度、伤害、攻击距离、敌人状态或冷却。

## 实际界面功能

背包不再只有物品列表。F2 的 AI 管理页与右键 AI 专属面板共用实时背包，选择物品再点击目标格，可转移、合并、整组交换、穿戴与卸下装备。跨页保留选择，真实物品改变则要求重新选择；操作由服务端在同一 Tick 校验双方背包快照及原生槽位规则，完整保留物品组件。客户端显示预览不会成为服务器物品来源。

切换会话后立即更新选中标记与标题；每个会话保留自己的草稿，旧读请求不阻塞新选择，也不会回写覆盖新会话。再次打开同一个 AI 的工作区会保留已选会话。专属面板补齐分页以及进行中、已归档、已删除筛选。

## 排查与验证

已扫描 50 个非测试原生界面源文件及其直接请求入口；43 个字面量请求均有服务端分发。467 处按钮构建调用不是 467 项已实测功能。空回调中的只读预览、HUD 绘制和窗口尺寸通知不被误认作业务操作。

新增回归覆盖真实 LDLib2 会话按钮、快速切换、草稿、历史正文、文件窗口返回、专属面板入口，以及真实背包转移、装备与服务端读回；战斗新增无弓对骷髅和长近战范围劫掠兽场景。当前尚未完成构建与原生验收，失败和最终结果在完成后补充。
