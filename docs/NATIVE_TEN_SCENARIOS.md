# AI 十项场景扩展

十类能力已接入 DivZero，下面分别记录实现、实际验收和边界。默认主题仍为 MC；只有玩家明确要求仿 Windows 或指定换肤时才覆盖目标界面的局部样式。F2 内置工作区保持不依赖 KubeJS，AI 创建的动态控件由 KubeJS 构建。

界面附加保留原菜单与物品槽；附加控件只消费命中自身的输入，关闭目标屏幕后移除宿主样式。实体 HUD 只处理客户端已追踪、范围内、可见的存活生物，默认不穿墙、不抢鼠标；各 AI/界面 ID 独立管理。记忆是数据，不构成世界或身体接管的新授权。

旧纯文本消息不会被猜测转换成按钮。预览按钮使用服务端登记的预览 ID，按世界/玩家校验且有缓存期限。预览不创建世界实体、不给予物品、不改变建筑。完成报告必须区分定义提交、客户端实际显示和游戏动作结果。

## 使用方式和边界

以上能力均已开放到对话工具。可以直接使用表格里的普通说法；不必手写脚本、复制界面文件或执行全局 reload。模型可以先观察当前菜单、已保存界面、实体、图片来源或记忆，再创建定义、检查回执并继续修改。真正的游戏操作仍须满足当前权限。

- 预览支持普通物品、原生实体、自定义模型、建筑文件和指定世界区域。大区域超出详细快照工作量时明确降为范围预览，不以空盒假称完整建筑材质已载入。
- 菜单附加按原版菜单 ID 或精确屏幕类定位。计时来自当前菜单同步数据，酿造配方来自实际注册表；按钮可通过原生预览工具显示产物。LDLib2 宿主允许撤销式 LSS 换肤；没有把一个 Mod 的测试结果扩展为所有 Mod 的私有 Renderer 都兼容。
- 桌面是游戏内控件树。`window` 自带拖动、调整大小、标题栏控制和任务栏；文件列表可以使用游戏文件库或界面数据。它不会因长得像 Windows 就自动获得本机文件/进程权限。
- 生物血条只覆盖客户端已追踪、距离范围内、可见的存活实体，默认处理遮挡，保持鼠标、移动和视角可用。不能为未加载的全世界实体凭空生成实时数据。
- 家和偏好按玩家、AI、世界隔离，并过滤已忘记/失效记录。“这里”的坐标固定为消息发送时的位置；记住地址不会自动执行传送或接管。
- 推土机有明确维度和施工边界，支持暂停、继续和停止。默认从脚部以上清除，不挖地板，不删容器和不可破坏块；仍尊重服务器权限与方块破坏保护事件。断线、死亡、越界会暂停，重启不自行恢复破坏。
- 换贴图只替换当前作用域的图片资源，并可恢复；不会改写 Minecraft 原始资源文件。透明 PNG 保留透明度，同一纹理 ID 被多个模型共用时这些模型也会变化。搜索结果带真实来源；不是任意网页图片都保证可下载。实际贴图应用/恢复已验证，额外的跨世界和重启恢复专项尚未执行。

真实模型验收覆盖家、偏好、跨会话回忆、装备给予、熔炉、血条和桌面。其它新增场景通过同一对话工具执行入口做零模型游戏验收，包含真实网络请求和渲染；不将这些样本称为每种内容、每个第三方 Mod 都已逐项通过真实模型测试。
