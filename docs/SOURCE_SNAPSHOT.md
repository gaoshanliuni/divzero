# DivZero 开发版源码快照

版本标识：`0.1.0-SNAPSHOT`。这是开发候选源码，不是完整 V1，也不表示已经创建 GitHub Release。

## 支持环境与构建

- Minecraft **26.1.2**、NeoForge **26.1.2.106**、Java **25**。
- 源码沿用技术包名 `dev.mineagent.runtime` 与 Mod ID `mineagent_runtime`，以保持兼容。
- Gradle Wrapper **9.2.1**；Maven/Modrinth 依赖版本与校验值在构建文件中固定。
- 设置 `JAVA_HOME` 为 Java 25，然后在仓库根目录运行 `./gradlew.bat :neoforge:jar`（Windows）；其它平台使用 `./gradlew`。
- Windows 的可选媒体二进制不进入 Git。完整媒体版先通过 PowerShell 7 执行 `./scripts/prepare-media-tools.ps1`，它从固定上游下载并核对 SHA-256；未准备时不应宣称外部媒体功能可用。
- 输出位于 `neoforge/build/libs/`。源码 ZIP 不是可安装的 Mod；游戏内 WebGUI 还需要对应版本的 WebGUI/MCEF 依赖。
- `./gradlew.bat ci` 只构建该快照并运行随快照提供的离线测试，**不是完整 V1 验收**。历史维护/Native smoke 任务可能依赖未公开的测试存档或单独下载的游戏依赖，不作为公共安装入口。

## 当前可用流程

- 原生 `@AI名字` 与 F2 对话；模型可以通过工具读取玩家、物品、世界和已加载方块，再依据真实回执执行操作。
- 当前权限下直接修改已有物品的名称/附魔/组件，给予已注册物品，执行 Minecraft 指令与 GameRule。
- 普通聊天可以生成独立 RuntimePackage 源码、模型与行为，发布后需在 F2 包目录选择、审查并明确启用。通用 HOT 物品载体支持包内彩色几何和真实 item.use/restyle：DeepSeek 生成的钥匙原样产物已验证给予背包、右键修改同一栈模型/名称、数量保持 1、停用拒绝。源码生成与批准后 Native 验收分阶段进行，没有用固定示例替代；载体不是热注册新的 FML Registry ID。
- 本人真实交互距离内的方块使用、原生菜单读取、整叠 QUICK_MOVE 和关闭。真实 DeepSeek 已完成只搬运箱中钻石、保留铁锭、关闭原生菜单并使用拉杆；实际客户端菜单、物品数量和陈旧请求拒绝均已核对。由模型读取/选择槽位，不要求玩家手输内部 ID；精确搬运 N 个及任意 Mod 特殊菜单尚未验收。
- 生成包可提供蓄力物品：服务端计时的 item.release/throwItem 将手中原件转为真实飞行实体，固体 AABB 碰撞反弹后可由原投掷者碰撞拾回；满背包保留，停用取消有效蓄力。真实 DeepSeek 近似球经历几何修正后，短/长蓄力、数量守恒及停止通过 Native；后续已补真实生成的球架/入框计分闭环；仍不覆盖任意 Mod 的 ItemEntity 专用拾取事件。
- AI 可发现并验证建模能力，使用 v2 参数化 sphere/torus 与平滑法线生成高精度几何，原 boxes/自由网格仍保留。真实生成的64×32主球最大三角面内缩约半径0.2405%，原生全分辨率3D预览和投掷回归通过。球面不再依靠堆盒子；物理仍是独立AABB；v2新增静态collisionMode=none视觉，配合独立solid边沿形成真正可穿过的空心通道。客户端和服务端应一同更新到本测试包。
- DeepSeek `deepseek-flash` 使用高强度 Thinking，工具续轮保留所需传输信息但不展示到聊天。不注入人工输出 token 上限；Provider 自身边界与应用传输/操作次数保护仍存在。
- 方块/流体延迟观察；真实模型自主建造与修正刷石机后，独立测试连续三次移除产物均由流体重新生成。
- 单人本机所有者可以发现和读取当前实例 `schematics` 目录的 Create 导出 NBT。当前只读结构和材料，不执行或放置 NBT，不读取详细方块实体参数。
- 联网工具提供 MC 百科站内搜索与公开 HTTPS 正文读取，回答需引用来源；不执行网页脚本、不携带游戏登录 Cookie 或模型 API Key。通用 DuckDuckGo HTML 后端在部分网络会返回验证码/202，遇到此情况明确失败，不伪造搜索结果。

## 八个对话示例

篮球/篮球架/蓄力投篮/原件拾回/实际入框计分、手持剑直接附魔、给予新附魔剑、找钻石无结果扩大范围、暮色森林巫妖攻略检索、死亡不掉落与关闭PVP、创造/OP刷石机，均有真实 DeepSeek 与 Native 证据。篮球经历真实生成失败与修正，最终原样产物完成偏投0分、两次命中2→4分、多次反弹重入不重复计分，客户端原生sidebar与世界模型绘制确认。不是硬编码旧篮球样例。

最新找矿是模型自主8→16→24扩大，返回真实钻石矿坐标；只扫描已加载范围、上限32格，不含自动采矿。攻略限定明确的Mod/Boss并带实际来源，不等于实战；刷石机已验证连续3次再生，不含生存资源获取。篮球先生成源码，再由玩家在F2包目录审查启用；测试玩家瞄准/拾回不冒充AI自动寻路。

通用 `awardScoreOnce` 原子保存事件回执及总分后投影Native计分板，同事件不重复累加；每板最多512事件/32行，容量满拒绝而非遗忘去重，新游戏使用新实例。原生sidebar会替换当前侧栏。生成器会在发布前校验models目录中的RuntimeMesh格式；静态拼接面有1e-7格接触容差，不放开实质重叠。

这些示例闭环不是完整V1发布，以下其余缺口仍保留。

## 新增能力

- 参数化基础几何新增box、plane、disc、annulus、cylinder、cone、frustum、prism、pyramid、ellipsoid、capsule；连同sphere/torus共13种。支持三轴方向、平滑/硬边、封盖/双面等有界参数，仍共用4096顶点/8192面预算。真实DeepSeek通过发现工具、完整根示例及字段错误提示，提供并成功验证了11种新增形状；本轮是实际只读几何解析，不冒称逐种Native视觉验收。
- F2桌面“更多”和对话“更多”均可打开“API设置”：选择地址模板/保存API URL，Key通过原生掩码输入、加密保存/清除，不进入网页或模型上下文。改变有Key的地址须确认后续凭据使用范围；不自动改模型或发起模型测试。
- 第8例已实际验证：DeepSeek自行发现已安装的网易云音乐，经本机确认后通过PowerShell打开，独立检查确认进程和可见窗口。没有内置软件路径或专用启动模板，没有下载安装。
- 这是通用 `inspect_host` / `host_command` 能力，不仅启动应用。当前仅Windows已安装PowerShell 7的单人本机Owner可用；每条完整脚本需原生确认，默认焦点取消，不打断Key输入。不申请额外Windows权限，不是文件系统沙箱，不允许远程服务器借游戏OP操作客户端电脑。
- 最长60秒、stdout/stderr各4096 UTF-8字节，真实exitCode/PID/状态，超时/取消停止当前执行器及观察到的子进程，但已发生的效果可能保留。持久operation防重放；输出会返回当前模型，只应读取当前任务需要的信息。脚本传输编码只解决Unicode/引号，不提供保密，审批显示明文源码。

## 配置与限制

API Key 只在本机游戏设置中填写，不放入聊天、代码、Issues 或截图。联网功能可由管理员在设置中开关。网页内容、蓝图、物品文字均为数据，不能增加世界/本机权限。

当前仍缺少：聊天修改已发布物品包及所有现存栈迁移、Create 及附属 Mod 运行兼容、任意 Mod 方块交互、完整种子地图、联网服务器的本机命令适配/非Windows平台、记忆 TTL 等。语音识别按当前范围跳过；不将这些项目描述为已交付。

优先在独立测试实例中备份后安装，不同时放入多个同 ID 的 Mod JAR。来源中不包含任何用户存档、API Key、私人聊天记录或测试运行产物。

公开历史与发布方式见 [PUBLISHING.md](PUBLISHING.md)。依赖与资源说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)；`.public-source-manifest.json` 列出本快照公开文件的校验值。

## 对话人设、外观、Buff与持续接管（2026-09-21）

- 可以直接说“以后你是简洁友善的星际向导”：读取当前AI的人设后按revision持久修改，同轮后续模型请求和未来会话使用最新版；不改变权限。人设不是尚未完成的实时记忆TTL功能。
- 可以说“把你的皮肤换成Alex”或“选个当前可用的YSM模型换上”：普通皮肤提供9人物×标准/纤细手臂共18款，也可复制聊天玩家的当前原生皮肤；不提供任意PNG/URL导入。YSM需要预先安装兼容版本和模型，切换即时生效、不需重启，卸载YSM本身才需重启。普通皮肤和YSM模式会互相清除旧覆盖。
- 可以说“给我60秒速度二级，隐藏粒子”“改成30秒一级”“只移除速度”：AI先读本人当前Buff和注册目录，再按hash写入/读回；正常倒计时不使hash失效；保留无关效果。写入使用本人真实游戏管理权限，不静默提权。
- 可以说“接管我，绕开障碍走到前面的金块，再看向石英块，等我下一条指令”：首次本机确认一次，后续不会每次规划都弹确认。左侧Native半透明HUD显示目标、公开行动摘要、下一路点及路线；不显示模型推理文本。
- 实际控制走原生键位和视角，不传送玩家；每项完成读取新观察，局部A*随新障碍/卡住重新寻路。真实DeepSeek测试中途中加入两格高石墙，玩家确实侧向绕行并到达金块、转向石英；仅一次批准、会话超过71秒仍保留。
- 达到目标进入IDLE待命而非退出，IDLE不持续请求模型。Esc或明确对话stop结束；普通游戏键鼠不结束；T/F2、失焦/界面暂时释放输入且会话保留。死亡/断线/世界或权限变化等异常保护仍停止；失败/未知保留待指令，不自动重试付费请求。
- 路径当前限已加载地面、单段水平16格/垂直8格、有界搜索，避开明显危险方块；不是全地图、飞行、游泳、载具或复杂容器自动操作。持续任务会产生后续模型调用，本机启动时明确提示。电脑PowerShell仍为逐条独立本机确认，不包含在身体接管授权内。

本批23次真实DeepSeek请求用于人设/皮肤/Buff/接管/YSM。YSM原生应用成功后的测试记录曾因Optional序列化失败而中断，原失败保留；修复测试后仅重用原参数在新实例做零模型原生复验，确认实际模型渲染。未把Mock或纯字段回执当作真实模型/视觉验收。仍是测试包，不是完整V1发布。
