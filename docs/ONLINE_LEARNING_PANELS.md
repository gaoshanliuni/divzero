# 在线学习生效、区域保存与请求悬停

## 实现

局内学习原先每次用固定步长执行三轮训练，只检查最后候选，候选偏移过大时整个更新被丢弃。现在从每轮候选中搜索缩小的参数更新，选择留出误差最低且通过原有参考偏移门槛的候选；没有提高原有门槛。每次采纳将模型版本增加一，服务端即时替换推理快照并原子保存。后续真实样本继续从当前已采纳权重学习。

旧检查点升级后会读取已保存回放并尝试一次新算法更新；开启学习也会使用已有回放，无需等样本计数正好再次整除 32。训练忙时新增的样本会在完成后继续调度，不阻塞游戏 Tick。关闭学习、重置权重和停止服务器会使过时回调失效。面板显示样本、已采用更新、模型版本与实际用于动作评分的版本。

行为区域保存具体边界、来源和半径，按世界/玩家/AI/执行身体隔离。重新打开面板恢复实际选择；改变半径会调整已选中心的边界，不再忽略新半径，也不会因玩家移动而自动移动旧区域。配置版本冲突或部分失败明确返回；普通全局面板不会广播所有玩家的区域资料。

游戏模式切换仅列出生存、创造和冒险；不改变原生命令对旁观模式的支持。响应许可消息将“请求”作为独立文本组件，悬停显示该次待批准请求的完整原文；四个许可按钮与权限范围不变。

## 评测范围

使用用户 e、w 的真实检查点副本，经游戏中的同一在线训练器生成并采纳更新，再导出冻结权重与内置基准进行原训练场对战。评测不把旧的同权重控制实验称为学习权重对战。冻结对局不回流训练；检查权重哈希、版本、真实动作评分次数及胜负。生产存档和原始检查点不覆盖。
