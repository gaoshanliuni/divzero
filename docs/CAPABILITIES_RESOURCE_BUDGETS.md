执行预算不能丢弃尚未分发的普通事件，先注册的脚本不能持续占据所有时间；单个脚本异常不能使无关脚本失效。需要即时返回决定的原生拦截事件保留明确的同步执行契约，异步任务由调度器推进，不能把世界 API 放到任意后台线程。

生成包仍须以禁用的候选状态完成签名、依赖、脚本及兼容性检查。只有持久化发布确定完成，才能执行自动生命周期步骤。HOT_RUNTIME/允许的热重载可进入运行；WORLD_REOPEN/BOOT_EXTENSION 只能登记待下次打开或启动，不能擅自重启。手动审批和目录/版本级启用入口保留。

方块实体创建不等于允许覆盖已有容器，碰撞策略不等于取消对真实玩家的保护，授权上传不等于开放服务器文件系统。每条路径都保留操作 ID、版本、权限撤销检查和实际回执。

## 脚本调度契约

普通广播 `fire` 按脚本保存回调队列，每次只执行一个回调后轮转；定时器与普通事件在每个脚本中交替，跨 Tick 保留未执行工作。`tick`、`server.tick`、`client.tick` 属于最新状态通知，积压时合并为最新值；普通事件不合并。队列不足时整次广播返回 `SCRIPT_QUEUE_PRESSURE_NOT_ENQUEUED`，不产生半次广播，调用方可等资源恢复再提交。取消、失权、卸载或换版本会清理旧版本的待执行回调。

即时交互、决策、生命周期及持久事件消费者继续使用 `fireTo`/`fireConsumer` 等同步接口，不能把必须立刻给原生事件的返回值拖到以后。一次同步事件共享执行期限；脚本超时只隔离当前作用域，不终止其它脚本。Java 主机调用返回后也检查实际耗时，但不能中断已经进入的任意 Java 阻塞调用；长任务应拆成合作式步骤，不能在服务器线程阻塞等待。

`resources.scripts.*` 设置公开调度时间、每 Tick 回调数量和待处理回调预算；包、缓存模块、处理器、定时器、跟踪资源数量改为告警阈值，超阈值不会禁止新的持久内容。预算更新不清空积压任务。资源观察返回实际耗时、待执行量、压力次数及软预算告警。

脚本可用 `off(event, callback)` 移除后续订阅、`cancelSchedule(id)` 取消尚未开始的定时器、`releaseResource(resource)` 关闭并释放已跟踪资源、`unloadModule(name)` 释放非入口模块的缓存（不撤销已有副作用或其它代码保存的引用）。`on` 返回注册函数，`schedule` 返回定时器 ID；按 `schedule(1, nextStep)` 分片的长任务沿用同一权限和服务器线程。已接受的事件快照不因随后移除订阅而被悄悄丢弃。

## 统一发布和后续增量

生成开始时保存目标维度/锚点与 RUN_CODE、MANAGE_PACKAGES 权限代次；发布先维持禁用候选校验，只有持久记录确定为 PUBLISHED 才进入自动执行。HOT 的每个定义使用持久分配的操作 ID；DATA_RELOAD 与 WORLD_REOPEN 复用既有原生数据包和重开计划服务。自动激活开始前记录 STARTED，结果未知不重新创建实例。聊天只读取统一回执，不再自己额外激活。失败候选修复后也进入同一路径。RESOURCE/BOOT 目前返回明确待处理状态，**尚不代表已启用或已登记启动**，必须继续完成。

原生权限复核扩展到交互能力、实体规则实际事件与延迟写入。实体规则记录持久权限代次，旧 RUN_CODE 对 EDIT_WORLD/EDIT_ENTITIES 的兼容授权也推进对应代次；脚本包、建造和实体权限仍各自独立。原生命令使用真实 command source，不将授权组转换为 OP。

几何 Ticket 使用独立、非持久的原生加载类型，按全服同时租约和每 Tick 启动数量预算排队；每个任务持一个移动租约，共享相同区块的原生 Ticket。分页中途等待保留行游标，避免重复前面的写入；完成、失败、取消和服务器停止释放。SAFE 默认继续保护活物，PLAYER_SAFE/CREATIVE 不以普通生物阻止几何；真实玩家只有 EXPLICIT 指定 UUID 才例外，类型/区域宽泛例外不包含真实玩家。

导航的每 Tick 总节点、切片节点、单次搜索节点、最小/最大时间和目标 Tick 时间均可配置；实际时间额度按服务器平均 Tick 耗时调整。AI 票总预算不限于 100、半径不限于 2，但会在分配前用长整数判断完整 footprint 是否容纳得下。尚需补齐高低优先级和更细的动态 Ticket 份额。

物品 PNG 仍为内容包声明资源，经现有分块资产协议传输。服务端要求对应真实可见物品/本人容器槽位，再核对实例、物品 part、来源版本和资源 ID；客户端复用纹理缓存。物品不再要求全部几何落在一格内，超出显示盒时自动适配；传输和渲染预算继续保留。静态视觉省略 collision 时不产生实体碰撞，动态物理仍拒绝无碰撞体。独立多材质与用户显式显示变换尚未完成。

NativeEntityCopyAdapters 允许安装的 Java 集成声明类型、版本和可复制标量字段；SAFE_STATE 内建公开 silent/nameVisible/年龄，CUSTOM 只能选已声明字段。不会提供任意 NBT 反序列化通道；适配前验证，适配后核对 UUID、世界、目标和乘客关系。RendererAdapters 在真实原生 submit 处选择显式控制器，提供抓取状态、应用动画、读回、finally 恢复的生命周期；未安装具体第三方适配器不宣称已兼容该 Mod。
