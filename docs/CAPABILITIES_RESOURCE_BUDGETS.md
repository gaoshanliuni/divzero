# 能力与资源预算升级

用户原则：不设置不必要的产品能力上限，保留可配置、可监控、可动态调度的服务器资源预算。这里区分持久内容数量、同时活动的资源、单次原生操作边界和每 Tick 执行开销。

执行预算不能丢弃尚未分发的普通事件，先注册的脚本不能持续占据所有时间；单个脚本异常不能使无关脚本失效。需要即时返回决定的原生拦截事件保留明确的同步执行契约，异步任务由调度器推进，不能把世界 API 放到任意后台线程。

生成包仍须以禁用的候选状态完成签名、依赖、脚本及兼容性检查。只有持久化发布确定完成，才能执行自动生命周期步骤。HOT_RUNTIME/允许的热重载可进入运行；WORLD_REOPEN/BOOT_EXTENSION 只能登记待下次打开或启动，不能擅自重启。手动审批和目录/版本级启用入口保留。

方块实体创建不等于允许覆盖已有容器，碰撞策略不等于取消对真实玩家的保护，授权上传不等于开放服务器文件系统。每条路径都保留操作 ID、版本、权限撤销检查和实际回执。


## 第一批实现进度

普通几何已移除“不能创建 BlockEntity”的限制，写入后额外核对原生方块实体确实生成，已有容器仍拒绝覆盖。新增 EDIT_WORLD、EDIT_ENTITIES 独立权限；几何、建筑、实体规则/状态/模板使用同一授权服务，旧 RUN_CODE 授权保留兼容，不把窄授权扩大成执行代码。循环预检查区分本循环的 break/当前函数的 return 与嵌套函数、switch 和不可达分支；运行时执行期限继续生效。

物品与对象 32/128、实例状态 256 项、对象模型缓存 128 项等累计数量门槛已移除，实例状态改为按需从数据库读取，并按可配置缓存预算回收。模型缓存超预算时逐出旧缓存、按需重新读取，不拒绝创建新内容。对象模拟采用按 Tick 的 FIFO 时间/数量预算，远处对象暂停模拟，持久内容不被删除；设置中提供活跃距离、对象模拟和缓存预算，inspect_packages 返回资源状态。此批还在编译/实机验证，不把源码改动计作全部 17 项完成。
