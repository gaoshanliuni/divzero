# HUD 编码资料、持续技能恢复与局内模型核验

## 本次修改

HUD Skill、工具说明和动态界面契约要求根控件在 `root.style` 中显式填写正数 `height`，同时设置合适宽度，普通状态面板避免 `height:100%`。新 HUD 候选缺失高度时返回 `$.root.style.height` 和修正示例，保留旧界面；旧保存定义仍可读取、隐藏和修复，不因升级直接删除。

`read_ui_wiki` 随 UI/内容能力组按需加载，普通聊天不携带资料全集。模组内置 7 篇当前桥接编码指南和 109 个官方资料目录项，支持搜索、分页、读取当前完整契约，以及通过已有公开网页读取器抓取选定官方主题。文档包括 HUD、LSS 布局、控件与绑定、事件回执、KubeJS 生命周期和候选修复。官方 API 比当前 JSON bridge 更广，文档明确区分可用桥接能力和需另行适配的 API。

2026-10-01 实际读取了 LDLib2 官方 KubeJS 与 HUD 文档，并从其导航建立目录；没有复制整站正文。KubeJS 官方 Wiki 在本机返回 HTTP 403，保留真实访问失败，不把 URL 目录当成已读正文；离线 KubeJS 指南基于当前 8.0.6 集成方式。官方读取失败不影响离线手册。

持续技能重启原先统一变为 PAUSED，并且没有自动重新绑定 AI 身体。现在 AI 的重启/暂时离线状态在主人回来、世界启用且身体、维度、权限和父任务仍有效时自动重新观察并恢复。真人托管、用户手动暂停/停止、临时工作栈和未核对的写入结果不会自动恢复；旧攻击不重放。关服不再将用户手动暂停覆盖成普通重启原因。脚本发起的工作另持久标记外部授权依赖，不因重启丢失回调而自动执行旧脚本意图。
