### 原生事件能力与模型、Python 界面优化

- 可复用原生事件能力：模板、目标绑定、版本更新、停用及解绑，复用原生交互规则与权限。能力工具按需加载。
- 自定义网格及碰撞每轴最大 100 格，支持 RGB/RGBA 与 PNG；补全生物和骨骼贴图资源的校验、传输和绘制链路。
- Python 状态原位更新为一条消息，查看代码后可点“返回”收起。已安装环境正常使用只检查必要文件存在，完整修复入口位于设置 → 更多设置。
- 设置新增 AI 玩家模型分类，AI 专属面板也提供独立模型配置入口，保留自定义模型 ID。

两种构建均通过编译、测试及打包检查。隔离实机已验证原生事件效果、错误候选保留旧版、贴图绘制、UI 尺寸 4 下两个模型入口保存与读回，以及 Python 单条状态更新、返回收起、环境复用和退出后修复。当前为候选包，尚未发布。本批验证记录见 [实现与验收范围](../EVENT_MODEL_PYTHON_UPGRADE.md)。
