### 进入世界后一键启用

- 初次进入世界或服务器，点击“一键启用”或输入 `/ai accept` 即完成本世界启用与客户端信任确认；也兼容 `/ai accpet`。
- 确认后自动连接工作区、刷新命令及内容状态，可立即使用，无需退出重进或手动 reload。
- 重复接受保留正在使用的工作区会话，禁用后也可在同一连接重新启用。
- 沿用服务器权限、AI 所有权和各玩家独立选择；不会将新加入玩家自动升为管理员。

包含 1.0.25 的 Key、模型设置和 F2 系统剪贴板修复。网络协议仍为 15，依赖版本不变。

已通过 GitHub Actions 构建与真实双客户端 LAN 测试：房主命令启用、非管理员访客按钮启用、重复接受、禁用后重新启用及双方状态隔离均通过，全程未重连、未调用模型。详见[验证记录](https://github.com/gaoshanliuni/divzero/blob/8524e19f3677ba6f607cb49b642701be82d34a3e/docs/WORLD_ACTIVATION_CHAT.md)。
