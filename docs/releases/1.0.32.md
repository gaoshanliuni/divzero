### 同一版本提供两种主模组

- `DivZero-mineagent-1.0.32-no-python.jar`：无 Python 版。构建时移除 Python 解释器管理、执行器、安装器和对应客户端实现；AI 技能明确显示“此版本不支持Python”。
- `DivZero-mineagent-1.0.32-with-python.jar`：内置 Python 版。完整捆绑 Windows x64 CPython 3.13.15、标准库、所需 DLL、固定基础库及许可证。

**两个主模组二选一，不要同时安装。** LDLib2、KubeJS 和 Better Advanced Tooltips 仍作为独立依赖附件提供，网络协议保持 15。

### 完整离线初始化与 Java 维护

- 首次确认使用后，Java 从 JAR 提取并校验运行时，离线准备专用环境；不下载解释器、不依赖系统 Python 或 PowerShell。
- 固定捆绑 requests 2.34.2、Pillow 12.3.0、NumPy 2.5.3、colorama 0.4.6，以及锁定的传递依赖。额外库仍需单独明确确认，不能隐式升级固定基础库。
- 启动、停止和子进程回收由 Java 完成。
- 停机更新／恢复使用内置 Java 维护程序，等待游戏进程结束并取得文件锁后才执行；保留原版本和操作回执。Python 环境损坏时可安排退出后修复，保留工作目录与历史记录。
- 原有逐操作确认、玩家身份、权限、取消和未知结果不重放机制继续生效。

平台范围：内置 Python 当前支持 Windows x64；无 Python 版的游戏功能不依赖 Python。客户端和服务端请同步更新。
