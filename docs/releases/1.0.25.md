### 补齐设置页的系统剪贴板

- API Key、ASR Key、模型设置等使用旧面板适配层的输入框接入系统剪贴板快捷键，与 F2 使用同一输入处理。
- 菜单附加层的文本框也接入相同处理，支持 Ctrl+A/C/X/V、Ctrl+Insert 和 Shift+Insert。
- 密钥仍以圆点显示；用户主动复制的是当前选中文本，不读取服务器保存的密钥。关闭面板时同步清空控制器和 LDLib2 文本框中的密钥草稿。
- 仅修复输入交互，不改变加密保存、权限检查或模型调用行为。

沿用网络协议 15 和现有依赖版本。此前的世界初始化热修复继续保留。

已通过 GitHub Actions 构建及隔离游戏中的真实系统剪贴板验证，覆盖 Provider Key、ASR Key、模型输入与 F2 中文多行复制粘贴。验证仅使用虚构密钥，模型调用为 0。详细范围见[验证记录](../native-workspace-integration.md)。
