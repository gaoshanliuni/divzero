### 聊天、摘要与朗读修复

- 历史摘要同时保留玩家原文、约束和 AI 正文，排除工具结果与思考。摘要关闭、等待与运行中的状态分别显示。
- 摘要正文预算默认 8192 UTF-8 字节，可配置 256–65536；后台整理不阻塞主回复，中断后按权限和预算恢复，明确停止的任务不会重启复活。
- AI 对 AI 会话并入普通聊天列表，显示 `[协作]`，支持玩家直接发消息；发送者身份保留。修复思考展开。
- 修复原生朗读接收与播放链路，使用微软免费 Edge 云端朗读，无需 Python 或单独语音 API Key。协议失败会返回具体状态。
- 玩家面向 AI 连续蹲起时，AI 在安全条件下面向最近的示意者回应；危险和原生工作动作优先。

### 创造能力与资源预算

- 批量几何支持创建箱子、熔炉、告示牌等方块实体，保留已有容器与机器的覆盖保护。
- 移除自定义物品与世界对象累计 32/128 数量硬限；活动资源按可配置预算调度、休眠与缓存。
- 验证成功的新包按生命周期自动启用或登记下次启动生效；保留候选隔离、权限、依赖检查和手动审批。
- 统一世界/实体编辑权限，增加受控区块加载、碰撞策略、脚本公平调度、导航/Ticket/磁盘预算配置。
- 增加物品模型纹理、多材质和变换、无碰撞静态模型、通用生物触发器、实体复制及 Renderer 适配器接口；观察接口支持分页，多人服务器支持授权蓝图上传。
