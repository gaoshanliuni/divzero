### 同一玩家的 AI 可以协同修改设置

- 支持向一个 AI 发出“所有 AI 跟随我”，通过完整同一所有者目录逐个执行并报告结果。
- 行为、战斗、学习开关、人设、皮肤和聊天设置支持指定另一 AI。
- 接通改名、游戏模式、自动重生、独立语言模型设置的对话工具。
- 保留不同所有者隔离、实际权限和版本校验；旧消息不能覆盖目标后来收到的停止或新指令。
- 能力按需加载，普通聊天不携带全部工具。

网络协议仍为 15，依赖不变。客户端与服务端需要同步更新。

### 修复新物品错误调用 Python

- “做一个召唤权杖”等新物品需求优先加载物品、内容包及相关实体能力。
- 未要求本机操作时，误选 Python 会返回具体原因和正确游戏工具，让 AI 在原对话中继续纠正，不弹本机执行确认。
- “不用 Python”等否定表达不再触发本机能力；明确要求的本机操作保持可用。

已在隔离游戏的受控流式对话中验证：误选 Python 后同一任务继续完成真实建模契约读取与模型校验，没有新增玩家提示词或本机执行确认。没有调用付费模型，也不以此冒称完整召唤玩法已验。

已通过云端编译和核心回归；隔离游戏验证 17 个同属 AI 的分页、批量跟随、设置读回、停止隔离和跨所有者拒绝。详见 [验证说明](https://github.com/gaoshanliuni/divzero/blob/main/docs/SIBLING_AI_SETTINGS.md)。
