# DivZero 原生界面与建筑升级状态

本次替换统一使用 LDLib2，默认 MC 主题。MCEF / WebGUI 的运行依赖、渲染器、桥接、下载、离线包和修复流程已从发布源码及安装产物移除，没有浏览器备用渲染。旧说明与失败记录作为历史保留。

## 已实现的使用流程

| 范围 | 当前实现 |
| --- | --- |
| 首次进入世界或服务器 | 聊天中选择启用或禁用；启用即时生效，无需输入 AI ACCEPT 或重新进入 |
| F2 / Ctrl+M | 同一套 LDLib2 工作区；窗口、会话侧栏、停靠栏和 MC 控件；内置界面不依赖 KubeJS |
| 右键 AI | 该 AI 的状态、血量、背包、人设、会话、内容、建筑和已保存界面入口 |
| 会话 | 流式消息、停止、历史、AI 自动标题、玩家重命名、摘要来源、请求详情、审计片段导入 |
| 消息选项 | 原生聊天与 F2 共用持久的确认、填入和复制选项；确认绑定原会话、到期及重复点击拒绝，填入保留已有草稿，重开恢复选择状态 |
| 内置管理 | 模型与 Provider、保密 Key、Workflow、文件、内容包、版本与实例、权限、偏好、双语、原生预览和代码编辑器 |
| 玩家决策 | 单选、多选、自定义方案、明确授权、稍后与继续、草稿和提交身份保留；回答与实际执行结果分开 |
| AI 创建界面 | 任意受支持控件树、样式、数据绑定和交互，由 KubeJS 构建；数据增量更新，结构候选验证后替换；失败保留旧版及输入 |
| HUD | LDLib2 ModularUI 覆盖层，按世界/玩家/AI/界面 ID 隔离；默认不抢输入，显式进入交互；支持重进恢复 |
| 菜单附加/换肤 | 熔炉计时、酿造台配方等独立控件附加；真实 LDLib2 宿主支持可撤销样式，其它屏幕支持附加控件与装饰 |
| 实体/物品/建筑预览 | AI 可自动打开或发送原生聊天/F2按钮；原生 Scene 支持旋转、平移和缩放，包含现场建筑材质快照 |
| 实体血条/桌面 | 跟随已追踪生物的被动实时控件树；可组合的桌面窗口支持拖动、缩放和标题栏/任务栏操作 |
| 对话记忆 | 异步读取有效事实与偏好；冻结发送时位置，支持自动记住家和装备搭配、跨会话取用 |
| 推土机/方块贴图 | 有界持续清除、保护事件和启停；网络搜索图片、作用域内贴图覆盖、图集像素核验及恢复 |
| 原生内容包 | 签名与版本校验、既有业务会话/RPC、资源、私有截图、布局保存、透明度及本地状态；权限继续由 DivZero 控制 |
| 几何 | 方盒墙/壳直接枚举边界；多边形墙厚、孔洞和可选封顶/封底；空心不会隐式清空内部 |
| 建筑计划 | 稳定构件 ID、模板、复制/镜像/阵列及方块状态变换；局部差异、步骤记录、暂停/继续、冲突检查撤销/重做 |
| 建筑完成 | 读取实际方块与状态，检查尺寸、门洞、通路与明确的支撑要求；验证绑定建筑/操作/范围/版本，未验证不能报告建成 |

## 安装与旧内容

Minecraft 26.1.2 / NeoForge 26.1.2.106。主模组 + LDLib2 即可使用内置工作区；AI 动态界面另需 KubeJS 与其依赖 Better Advanced Tooltips，Rhino 已内嵌。版本和许可见 [安装说明](NATIVE_INSTALLATION.md)。

旧 HTML/CSS/DOM 内容需要通过迁移入口明确重写为原生定义；不原样运行，不恢复 MCEF。内容包的无关资源、身份与玩法代码应保留，并按具体业务验收。源码使用独立公开历史同步；未自动发布 Release，也未覆盖生产存档或配置。
