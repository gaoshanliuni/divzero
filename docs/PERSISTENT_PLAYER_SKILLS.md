# 持续玩家技能升级（进行中，尚未交付）

本轮完整目标是漫步、跟随、巡逻/警戒、战斗、钓鱼和农务，以及它们之间的抢占和恢复。AI 身体继续为 `MineAgentPlayer extends ServerPlayer`。真人接管也必须支持相同目标、感知、导航与技能生命周期，通过独立的客户端输入适配器执行，保留 Esc 停止、界面/失焦暂停与身份校验；不得用服务端移动冒充真人输入。

参考用户指定的 [TouhouLittleMaid-26.1](https://github.com/TouhouLittleMaid/TouhouLittleMaid-26.1)，本次读取版本 `73673c66db4f43bb8f1e750611e3af3696d20bb5`。重点是 `IFarmTask` 的作物适配、移动与到位动作拆分，`MaidPathFindingBFS` 复用节点判定器，以及实体跟随与水陆导航的分工。当前新增代码为 DivZero 独立实现，未复制其源码/模型/纹理，不增加女仆必装依赖。该仓库许可明确只将代码部分列为 MIT；未来若移植源码应保留原版权和许可，不推定资源许可。
