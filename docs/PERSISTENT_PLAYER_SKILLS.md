# 持续玩家技能与真人托管

> 1.0.21 的独立战斗策略、连击/突围、平台风险与最新双击 Esc 规则，见 [本地战斗与工作模式](TACTICAL_PLAYER_BEHAVIOR.md)。下文保留 1.0.20 阶段的验收记录。


AI 身体继续使用 `MineAgentPlayer extends ServerPlayer`。跟随、漫步、巡逻、警戒、战斗、农务和钓鱼由同一套持续技能运行时管理。真人托管复用目标、感知、导航和生命周期，通过独立客户端原生输入适配器执行，不用服务端传送冒充移动。

普通对话可要求“照顾这片田，成熟收割并补种，直到我停止”。模型读取现场后提交技能，本地循环负责走位、成熟度检查、收割、补种与等待。模型结束回复或暂时不可用，不会使已经启动的工作循环消失。明确要求“接管我的身体”才使用 `actor=player`。

## 托管操作

- 启动时释放鼠标，LDLib2 MC 面板显示当前目标和公开行动摘要。
- **T、F2、切换电脑窗口及最小化不会暂停工作。** 游戏内动作通过独立输入通道执行，不向其它桌面程序发送按键。
- “暂停 / 继续”保留当前任务；“追加命令”打开已填入 AI 名称的聊天框；“退出”结束托管。按钮松开时触发并显示按下反馈。
- **ESC 结束托管**，其它普通输入不自动结束。断线、死亡、世界、身体或权限变化仍释放控制。
- 托管期间临时关闭 `pauseOnLostFocus`，退出后恢复玩家原设置，不永久修改游戏选项。

## 实现

| 部分 | 行为 |
| --- | --- |
| 导航 | 保留搜索 frontier 的分片计算；区分找到路线、预算耗尽、未加载、无路和无效目标；失败退避，空路线不能绕过等待 |
| 通行 | 路线、工作站位和漫步共用判定；门、低通道潜行、台阶、跳跃、下落、梯子、水域与上岸作为动作处理 |
| 跟随 | 保存实体 UUID；追赶和停止距离分开；更新同一导航意图，不逐 tick 清空路线；默认不靠传送追赶 |
| 巡逻 / 警戒 / 漫步 | 顺序或往返路标、停留与进度保存；限定区域警戒；从实际可达区域选漫步位置 |
| 战斗 | 威胁感知、近战冷却、弓蓄力释放、原生重力与消耗、伤害回执；工作被防御打断后重新检查并恢复 |
| 农务 | 原生收获、耕地和种植；到位重检、种子检查、短期工作点预约；六种原版作物适配及扩展入口 |
| 钓鱼 | 查找水和岸边、原生鱼竿、绑定实际钓钩、真实咬钩、收竿与掉落验证；掉落不冒称已拾取 |
| 控制权 | BehaviorArbiter 父意图与 ActionControlLease 子动作统一；技能瞄准与导航注视分开 |
| 生命周期 | RUNNING / WAITING / SUSPENDED / PAUSED / COMPLETED / FAILED / CANCELLED；等待成熟、被打断、暂停和取消分别记录 |
| 持久化 | 异步 SQLite CAS；保存 owner、世界、维度、身体、任务意图和回执；重启保留状态，核对后显式恢复 |
| 调度 | 共享扫描与轮转寻路预算；长期会话不永久占用普通动作批次，不被其单次动作超时终止 |

接口包括 `inspect_skills`、`start_skill`、`follow_entity`、`patrol_route`、`guard_area`、`farm_area`、`fish_at`、`wander_area`、`combat_entity`、`control_skill`，接入普通对话、脚本和标准世界动作。启动回执不代表目标完成；查询返回阶段、原因、计数及实际证据。通用托管规划协议也支持经过校验的 `SKILL` 交接，避免逐株、逐步规划。

确认尚未发出的操作可在打断后重新检查执行。已可能消耗物品或改变世界、但回执不确定的操作先暂停核对，不盲目重放。陈旧任务或取消后的回调不能继续执行。等待中的自有钓钩在防御打断时取消，之后重新抛竿；已发出且结果未知的收竿仍按不确定操作处理。

| 作物适配 | 小麦、胡萝卜、马铃薯、甜菜、下界疣、甜浆果；空手浆果交互、锄地与种植；`e30a88de-4605-4db5-b821-3e634a518880` |
| 实际重启 | 保留暂停 revision 2、库存和计数；160 ticks 不重放，显式恢复后继续；`8aa39c13-92df-47a4-8ae8-e77191c98efb` 独立 resume 记录 |
| 不确定回执 | 种植后注入确认中断；拒绝盲目恢复，读方块/库存核对后恢复，不多消耗种子；`760f118b-4de6-4703-b159-c77b5eb29165` |

真实模型采用官方 `deepseek-flash`、`thinking=enabled`、`reasoning_effort=high`，未设置 `max_tokens`。AI 身体自然对话农务通过 10 次请求；真人自然对话农务修复后通过 7 次请求。模型自行读取现场并创建技能，对话结束后继续工作，再次成熟的作物也能处理。测试没有预先提供技能定义。

通用托管规划器另行通过 1 次真实请求：模型根据实际观察返回 SKILL，创建 FARM/player，会话保持原接管身份，通过真实客户端输入继续种植和收获；运行 `5d25fb39-73c5-4c63-bc98-d87a83a1258f`。测试只提交自然语言目标，没有预先提供技能定义，未把交接后继续做下一株夸称完整生长周期。

另保留一次不通过的真人测试：10 次请求仅进行了旧逐步规划，没有持续技能，未列为通过。现已修正冲突工具指引并验证通用规划器 SKILL 交接。上述四个隔离测试共 **28 次开始、28 次完成**，不与此前十项界面能力的 38 次混算。失败记录不删，未知请求不重放。

验收覆盖上述地形、原版作物、剑、弓和鱼竿，不表示所有第三方作物、武器、载具、飞行或全部地形已兼容。盾牌撤退策略和任意第三方适配尚无完整专项联验。16 身体预算是测量样本，不是任意规模 TPS 承诺。真人自然对话专用技能入口与通用规划器交接分别验收，不将解析测试充当游戏执行结果。
