# DivZero 全部功能与使用范围

[返回首页](../README.md) · [下载版本](https://github.com/gaoshanliuni/divzero/releases) · [安装说明](BUILD_JAR.md)

本文面向玩家，汇总当前公开 `main` 的功能，替代散落的历史开发记录作为玩法索引。**当前是开发测试版，不保证任意 Provider、Mod、平台和组合均可用。** Minecraft 26.1.2、NeoForge 26.1.2.106、Java 25；协议5，客户端与服务端一起更新。管理操作需要开启作弊／真实管理权限，首次可用 `/ai accept` 初始化。

## 1. 对话、模型与 AI 管理

| 功能 | 使用方式与现状 |
|---|---|
| 原生聊天 | `@AI名字` 选中 AI，Tab 自动补全；用自然语言提需求。 |
| F2 对话 | 持久历史、新建／切换会话、查看原文、归档／恢复与上下文详情。 |
| 流式回复 | 边生成边显示；超过原生聊天单条长度时拆分发送，不用截断代替完整回复。 |
| 打断与恢复 | 运行中可点击“打断并发送”；失败可“核对后继续”，先读真实状态，不盲目重放未知写操作。 |
| 思考显示 | 原生显示 `[AI名字][思考]…`，可切换显示；F2 历史默认折叠。只显示 Provider 实际返回内容。 |
| Provider | DeepSeek、OpenAI 兼容 API、GLM 智谱／Z.AI、Ollama 等配置入口；GLM 尚未做真实凭据联验。 |
| 模型选择 | 保存 Key／URL 后获取 `/v1/models`，列表选择；选择“使用自定义模型”才显示名称输入框。 |
| 每 AI 模型 | 各 AI 可使用全局模型或单独指定当前兼容 API 的模型，不改变其它 AI；不是每个 AI 一套独立 Key。 |
| AI 数量与名字 | 不保留旧4个创建上限；目录分页、名称分包补全，已有70名 Native 测试。硬件／区块资源仍有限。 |
| 长任务 | 对话已移除旧12轮／32次累计上限；保留主动停止、Provider／传输边界和失败不重放。 |
| 彩色互动消息 | AI 可设置聊天颜色，发复制、填入输入框、确认选择等可点击消息。 |

## 2. 人设、长期记忆与外观

- **对话设置人设**：例如“以后你是星际向导”，保存后同轮后续和新对话读取最新人设。
- **事实／偏好记忆**：AI 自主读取、保存、更新、删除；同主题新值替换旧值，实时事实可设置过期时间。键自动生成，不让玩家输入内部 ID。
- **内置／玩家皮肤**：18款内置人物与体型、复制玩家皮肤。
- **PNG 热换肤**：选择本地 PNG，或让 AI 生成、导出、修改标准 UV 像素画；64×64、旧64×32，wide/slim。保留同一 AI 身份、名字、跟随与任务。
- **YSM**：安装兼容 YSM 和模型后选择目录内外观，热切换无需重启；卸载 Mod 本身仍需重启。PNG/YSM 所有组合尚未逐一验证。

## 3. 读取与修改现有世界

| 能力 | 说明 |
|---|---|
| 玩家信息 | 手持物、背包、装备、位置、视角、生命／饥饿／经验等当前信息，以及可读取的出生／死亡点、成就、可见实体。未知或缺失字段不会编造。 |
| Buff | 读取、给予、修改等级／时长、移除指定效果，保留其它效果。 |
| 原版／已注册物品 | 直接修改背包／手持物的名字、附魔和组件，或给予新的已注册物品，无需先丢到地上。 |
| 方块观察／找矿 | 最大4096³坐标范围，按游标分页；可扩大搜索。不强制加载整片世界，不把未加载区块当成“没有”。 |
| 原生交互 | 近处方块使用、容器读取、整叠快捷移动、原生菜单开关、拉杆等；任意 Mod 特殊菜单不保证兼容。 |
| 指令与 GameRule | 使用玩家真实命令权限发现／执行游戏指令，例如死亡不掉落、PVP、计分板；不暗中提高 OP。 |
| 完整命令输出 | 保存并分页续读，超过首回执预览不等于余文被丢弃。 |

“帮我给手里的剑附魔”“只移除速度”“打开死亡不掉落并关闭PVP”都可以直接对话提出。

## 4. 建筑与几何建造

支持线、平面、墙／壳、非矩形拉伸、坡面、Bezier 曲线、双线性曲面、圆柱、椭球、圆顶，以及镜像、旋转、阵列／路径重复、材料规则、完整 BlockState 和局部替换。

单计划包围盒最大 **2048×2048×2048**，磁盘分页、分 Tick 操作。实际仍受世界高度／边界、已加载区块、权限、磁盘及旧状态预检约束，不代表已做全体积填充性能验收。部分完成要按回执处理，不自动覆盖重放。

刷石机已在真实 DeepSeek 建造流程后验证连续三次圆石再生；不把“放好方块”直接当成机器能工作，也不冒称已自动获取全部生存材料。

## 5. 实时创造物品、模型与玩法

- 新物品／模型／规则由 AI 生成独立内容包，不是只能选择硬编码演示物品。
- **13种参数化基础图形**：box、plane、disc、annulus、sphere、torus、cylinder、cone、frustum、prism、pyramid、ellipsoid、capsule；支持自由网格、平滑法线和几何验证。
- 可定义右键交互、改变同一物品模型／名字、蓄力释放、投掷、反弹、拾回、碰撞触发和计分。
- HOT 内容生成后自动启用；AI 可读内容包与实际实例状态。原生计分板支持持久去重记分。
- 篮球示例已实测蓄力投篮、偏投0分、两次命中2→4分、原件拾回。

**边界**：使用通用热载体，不是任意热注册新的 FML Registry ID；任意已发布物品的全部存量迁移、任意 Mod 专用拾取钩子仍需适配。

## 6. 实时创造生物并互动

支持**友好、中立、敌对**三类阵营，自定义几何外形、属性和多种组合行为：

| 交互方式 | 当前能力 |
|---|---|
| 村民式 | 右键打开原生交易窗口。 |
| 猪灵式 | 附近丢下物品，消耗输入并掉出交换结果。 |
| 靠近触发 | 消息、Buff、给物品、声音；可设带引信爆炸，离开范围可取消，默认不破坏方块。 |
| 僵尸式 | 敌对主动攻击，中立受击反击。 |
| 羊式 | 喂食、同物种繁殖。 |
| 马式 | 主人空手普通右键骑乘，实际控制移动。 |
| 狗式 | 跟随、停留、受令战斗、巡逻；可取消跟随。 |

![实际生成的星球伙伴](images/creature.png)

生物定义可更新并持久保存。当前模型以几何颜色为主，不宣称支持任意外部纹理、骨骼动画或任意脚本触发。骑乘／交易／喂食冲突时按当前交互契约选择，详见技术范围。

## 7. AI 身体与玩家接管

- **AI自己的实体**：移动／局部寻路、转向、奔跑、选物品、丢物品、跟随、停止跟随、传送到玩家。
- **接管本人**：玩家明确提出后直接启动，无逐轮二次确认。持续观察和重新规划，左侧 HUD 显示公开决策摘要与下一路点。
- 到达目标进入待命，不因旧45秒上限退出。**Esc 或明确要求停止**结束；T/F2、失焦和界面暂停输入但保留会话，死亡／断线／世界或权限变化会保护释放。
- 当前是已加载区域的局部地面导航，不保证飞行、游泳、载具或任意复杂 GUI 自动操作。本机电脑命令不包含在身体接管授权里。

## 8. 搜索、通用文件与建筑导入

- 搜索 MC 百科、建筑站点和公开网页，读取正文并引用来源；登录、验证码或读取失败会明确报告，不伪称已联网成功。
- 建筑有公开直链时可下载；无法自动读取时，聊天按钮打开 F2 文件窗口，选择上传并“交给AI”后继续。
- F2 顶栏“文件”、对话“附件”：文件／文件夹、空文件／空目录、二进制、文件夹 ZIP 下载；AI 可读取、创建文件和提供下载按钮。上传不等于执行。
- 文件传输只监听 `127.0.0.1:25510`，按 Owner／世界认证；不是公网网盘。单份上传8GiB、自动直链下载64MiB，现阶段单人本机使用。

| 导入类型 | 范围 |
|---|---|
| Litematica `.litematic` | 多 region、负 Size、palette 与完整状态。 |
| Create／原版 `.nbt` | 结构蓝图，不要求把它当可执行脚本。 |
| Sponge `.schem` | v1／v2／v3。 |
| 旧 `.schematic` | 原版数字ID映射；旧 Mod ID 需相应适配。 |
| Java 世界／ZIP | Anvil 世界选区、建筑 ZIP 合集；不运行上传的世界。 |

可选朝向、旋转和镜像。**当前默认保留内容**：源空气、BlockEntity／容器、选区实体及支持格式中的延迟 Tick，也可关闭。原文件不修改，不安装源玩家数据、配置或数据包。

## 9. F2、预览、悬浮窗口与实时网页

- 独立半透明窗口，可分别显示／隐藏、最小化、关闭、悬浮；不是一个总开关。AI 可按权限改变窗口状态。
- 一级“包管理”、文件与附件入口；较少使用的设置进入更多菜单。
- 模型／结构预览：左拖自由旋转，右／中键平移，滚轮双向缩放，复位；不再依赖预设视角下拉。
- 大建筑可能显示范围预览，建筑颜色采用近似投影，不冒称完整原版材质渲染。
- 生成 WebUI 可持续读取坐标、附近方块等真实信息；后台暂停、关闭释放、上下文失效停止。刷新读数不需要每次调用模型。

## 10. 内容包与高级运行生命周期

支持当前／历史版本查看、校验、复制、启用，以及资源／数据／客户端代码等专用流程：

- HOT：启用未激活定义，生成后可自动启用。
- 历史版本：复制成独立包再启用，不覆盖当前 head 或现有实例。
- 资源包／数据包：真实下载、验签、重载与结果读回。
- WORLD_REOPEN：保存计划，正常重开后生效；不把“待重开”说成已加载。
- BOOT／CLIENT 原生代码：保留专门安装／执行和每台本机的确认，不以服务端 OP 代替客户端许可。

Web高级管理和底层能力保留；冗余原生 Code Studio、媒体、计分板、创造器专用页面已移除。技术 revision/hash 留在详情用于核对，不要求玩家手工输入。

## 11. 本机 Python、依赖安装与完整输出

Java直接管理固定校验的 `python-build-standalone install_only_stripped`、专用venv及Python／pip进程。AI可用Python完成本机任务、安装第三方库；不再调用旧PowerShell执行器，不依赖系统Python。

每次在**原生聊天**查看代码、确认或拒绝，运行后可停止。只对当前Windows x64单人本机Owner开放；不提权、不借远程服务器权限执行。脚本与安装不是文件系统沙箱，确认前应核对实际任务。

完整stdout/stderr保存并分页读取；超时／取消可能留下已发生的效果。未知结果先核对，不自动重跑。实际DeepSeek已安装colorama、读取版本、启动隐藏子进程并保存结果。

## 12. 语音、媒体与尚未完成的范围

- **语音识别 ASR：按用户要求跳过，最低优先级。** 不将相关入口或历史协议算作已交付。
- TTS／媒体基础能力和可选多媒体构建保留，但不保证任意平台、播放源、生成服务或聊天控制组合。
- 完整种子地图、任意 Mod 自动适配、全部存量内容迁移、多平台本机命令、联网服务器的本机文件协作等仍不是“全部完成”。
