# 施工移动与短缺口跳跃

2026-11-08 增量，原生验证进行中。

施工导航原先把 `moveCarefully` 等同于持续潜行，宽阔地板也受到潜行速度限制。现在谨慎移动只开启地形判断：低净空或脚下及前方缺少足够支撑时潜行；有安全通道、食物和足够制动距离时使用原生疾跑；接近操作点后收敛到准确站位。真人接管使用同一服务端判断和原生按键，手动潜行与战斗策略仍保留独立控制。

原寻路图只接受横向相邻节点，因此不能表达跨过一格或两格缺口。新增 `GAP_JUMP` 路径动作：先核对实际起跳力量、重力、移动能力、空中碰撞和落点，再比较跳跃与绕行成本。当前明确支持同高度的直线短缺口；低顶棚、未加载区块、危险或缺失落点、无法疾跑等条件不会强行跳跃。动作通过原生起跳、移动或真人输入执行，不瞬移、不抬高速度属性。起跳、空中接近和实际落地各自保留状态，未落地不会提前判定到达。

原生专项场景覆盖宽地板疾跑、窄边沿潜行、有可绕行路线的一格/两格缺口，以及低顶棚和落点被移除后的拒绝。结果以实际移动、起跳、最低高度和到达状态为准；仅新增路径类型或通过编译不算验收成功。

此前真实 DeepSeek 房屋方案的恢复运行 `82ad172e` 已执行 178 次原生放置，最后一根高处柱子因三次跳跃未获得放置窗口暂停。用户已确认观察角色占位，要求停止对此问题的追查。后续隔离场景把观察者移至施工范围外，不改建筑方案或放宽实际碰撞检查。完整房屋、盔甲入箱及协作对话界面验证继续保留，不以本项移动改进替代原任务。
