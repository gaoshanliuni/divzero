## 开发包与地图

### 安装与开始游戏

1. 将 **Forge 1.8.9 开发 JAR** 放入该版本的 `mods`，并完全退出、重新启动 Minecraft。只放地图 ZIP 不会加载 Mod 或开始界面，NeoForge JAR 也不能使用。
2. 将地图 ZIP 解压到该版本的 `saves`，确保 `saves/<地图目录>/level.dat` 存在；ZIP 不是 Mod。没有加载 DivZero 时不要继续保存这张含自定义方块的地图。已误开的存档保留，另建完整地图副本。
3. 单人进入地图后装备面板自动打开。选择装备，点击 **开始游戏**，等待清场和 5 秒倒计时。首次点击同时启用此世界的 DivZero，不需要作弊或 OP；面板明确提示替换背包。
4. 面板关闭后按 **P**（可在控制设置改绑），或 **Esc → PvP · 开始 / 装备 / 停止**。HUD 同时显示当前改绑键；`/ai duel equip` 仍可使用。对局中可从同一面板停止。
5. 死亡后使用原生重生回到大厅，再次点击开始。每局最多 3 分钟；取消不增加胜负统计。

`.4` 增加首次一键启用并开局、P 和暂停菜单恢复入口。`a67bc26` / [Actions 37286140110](https://github.com/gaoshanliuni/divzero/actions/runs/37286140110) 产物已完成干净 ZIP → 两个恢复入口 → 一次点击 → 实际对战 → 重生 → 下一局 → 停止，回执 `NATIVE_CLEAN_TEMPLATE_PLAYABLE_PASSED`。实际界面比例 4；AI 移动约 19.29 格、实际近战命中 6 次击败不反击的测试玩家；未授予 OP、全局战斗规则修改仍拒绝。此为自动测试，不能推导真人胜率。

此次检查同时发现树叶模型带有 `parent` 和 `elements`，被 1.8.9 拒绝。移除冲突的父模型声明并同步资源生成脚本；保留原生树叶贴图引用及六面染色。

游戏使用 Java 8，服务使用 Java 25。可通过 `divzero.java25` JVM 属性指定 Java 25 可执行文件；也支持发现标准 Minecraft `java-runtime-epsilon` 位置。完整图形安装向导仍待实现。

开发入口为 `/ai enable`、`/ai create 名称`、`/ai worker`、`/ai offhand`、`/ai swap`。副手快捷键默认 F，窗口默认 V。`/ai combat modern|legacy` 需要已有管理权限。标记地图使用 `/ai duel equip|ready|stop|status`。

`tools/package_arena.py` 从**已关闭且通过 Native 导入的存档**导出新的 20 区块模板，保留地形和必需 Forge 注册表，清除玩家、AI、实体、掉落物和统计，生成新世界身份并关闭作弊。原存档不修改，已有输出不覆盖。输出标记为开发模板，不是完整 Mod 发行。
